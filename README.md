# python-module2

## Описание проекта

Программа предназначена для расчёта расхода мобильного интернета абонента за выбранный период. Она позволяет определить общий объём использованного трафика, остаток пакета или превышение установленного лимита, а также рассчитать дополнительную оплату.

## Основные возможности

- Ввод ФИО абонента.
- Ввод ежедневного расхода мобильного интернета.
- Выбор периода расчёта от 1 до 10 дней.
- Расчёт общего расхода интернета.
- Определение остатка или превышения пакета.
- Расчёт дополнительной оплаты.
- Определение статуса использования пакета.
- Расчёт процента использования пакета.
- Отображение расхода интернета по каждому дню.
- Возможность повторного расчёта.

## Тарифные условия

- Размер пакета: 10 ГБ.
- Стоимость каждого дополнительного ГБ: 500 тенге.
- При расходе менее 8 ГБ — «Запас достаточный».
- При расходе от 8 до 10 ГБ включительно — «Пакет заканчивается».
- При расходе более 10 ГБ — «Пакет превышен».

## Используемые технологии

- Python 3
- Условные конструкции `if-elif-else`
- Циклы `for` и `while`
- Функции с параметрами и возвращаемыми значениями
- Форматированные строки (f-strings)

