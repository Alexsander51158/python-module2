# Папка data

## Назначение

Папка предназначена для хранения исходных данных, необходимых для работы программы.

## Использование в проекте

В текущей версии программы внешние файлы и базы данных не используются. Все необходимые данные вводятся пользователем непосредственно во время выполнения программы.

## Возможное расширение

В дальнейшем в папке можно хранить:
- Файлы с тестовыми данными.
- Примеры расчётов.
- Данные абонентов для проверки программы.
