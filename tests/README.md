# Тестирование программы

## Цель тестирования

Проверка правильности расчёта расхода мобильного интернета, определения статуса пакета, остатка трафика и дополнительной оплаты.

## Тестовые случаи

### Тест 1 — расход ниже пакета

**Входные данные:**
- Ежедневный расход: 1 ГБ
- Количество дней: 5
- Размер пакета: 10 ГБ

**Ожидаемый результат:**
- Общий расход: 5 ГБ
- Использование пакета: 50%
- Остаток: 5 ГБ
- Превышение: 0 ГБ
- Доплата: 0 тенге
- Статус: «Запас достаточный»

**Фактический результат:** совпадает с ожидаемым.

### Тест 2 — пакет заканчивается

**Входные данные:**
- Ежедневный расход: 1,5 ГБ
- Количество дней: 6
- Размер пакета: 10 ГБ

**Ожидаемый результат:**
- Общий расход: 9 ГБ
- Использование пакета: 90%
- Остаток: 1 ГБ
- Превышение: 0 ГБ
- Доплата: 0 тенге
- Статус: «Пакет заканчивается»

**Фактический результат:** совпадает с ожидаемым.

### Тест 3 — превышение пакета

**Входные данные:**
- Ежедневный расход: 2 ГБ
- Количество дней: 6
- Размер пакета: 10 ГБ

**Ожидаемый результат:**
- Общий расход: 12 ГБ
- Использование пакета: 120%
- Остаток: 0 ГБ
- Превышение: 2 ГБ
- Доплата: 1000 тенге
- Статус: «Пакет превышен»

**Фактический результат:** совпадает с ожидаемым.

## Итог тестирования

Программа успешно прошла три тестовых случая. Расчёт общего расхода, остатка пакета, превышения, дополнительной оплаты и статуса выполняется корректно.
